# MotoNav Web — prototipo
PWA de navegación minimalista para moto.

Incluye GPS, OSRM, OpenStreetMap/Nominatim, ruta simplificada, distancia, velocidad, recálculo, modo brújula, Wake Lock y PWA.

Para probar necesita HTTPS (o localhost). Para desarrollo:
`python -m http.server 8080`

La primera versión usa los servicios públicos de OSRM/Nominatim; para uso continuo conviene configurar un proveedor propio.
